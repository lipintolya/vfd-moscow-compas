# Семантическое ядро: какие запросы какая страница закрывает

Источник — подсказки поиска Яндекса (`npm run seo:suggest`, снимок 30.10.2026 в `suggest.json`): порядок и частота появления подсказок показывают, что ищут чаще. **Частоты Вордстата здесь нет**: он открывается только из кабинета Яндекса. Колонку «Вордстат» заполняет владелец или тот, у кого есть доступ (список запросов — `wordstat-queries.txt`, по одному в строке).

Приоритет владельца (30.10.2026): стеновые панели → скрытые двери → межкомнатные двери → перегородки. Плинтусы и входные двери не в приоритете.

Правило: новая страница нужна, только когда у запроса есть отдельный смысл **и** настоящее содержание (факты салона, товар с ценой, реальные работы). Дублировать сетку каталога под другим адресом нельзя.

## Что не сделано намеренно

- Отдельные страницы «стеновые панели в прихожую / спальню / гостиную» и «двери-невидимки» отдельно от скрытых дверей: те же товары и тот же текст, это дубли. Закрыто разделами и синонимами на существующих страницах.
- Страницы с ценами за м² для панелей и перегородок: салон их не называл.

## Как обновлять

1. `npm run seo:suggest` — свежие подсказки в `suggest.json` (затравки — `seeds.json`).
2. Сверить новые запросы с таблицей, внести в нужный кластер.
3. Частоты из Вордстата — в колонку, чтобы видеть, какие пробелы закрывать первыми.
