# Баннеры акций

Баннеры от заказчика (11 ноября 2026), 1254×1254: на сайте — в блоке акций
главной и на `/akcii/`. Имя файла = `id` акции в
`cms/scripts/promos-2026-12.json`; там же подпись к баннеру (`bannerAlt` —
что на фото и какая на нём надпись).

Как поменять баннер на сайте:

1. положить новый файл сюда под тем же именем;
2. остановить Strapi, `npm --prefix cms run add:promos` — баннер уйдёт в
   медиатеку и встанет в поле «Баннер», запись опубликуется (прежний
   загруженный скриптом баннер удаляется);
3. запустить Strapi, выложить сайт.

Свой баннер, загруженный в админке вручную, `add:promos` не заменяет.
