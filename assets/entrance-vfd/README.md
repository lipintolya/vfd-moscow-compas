# Входные двери VFD со сменными накладками

Фото блока «Входные двери VFD со сменными панелями (накладками)» на `/catalog/vhodnye-dveri/`.
После любых изменений: `npm run gen:entrance-vfd` (копии в `public/renders/entrance-vfd/`).

- `models/<модель>-outside.webp` — дверь снаружи; `models/<модель>-render.webp` — дверь в интерьере (визуализация).
- `skins/<накладка>.webp` — накладка: дверь изнутри.

Имя файла — id модели или накладки из `src/data/entrance-vfd.ts`; файл без записи или запись без файла —
ошибка сборки. Накладка без фото в список не попадает.
