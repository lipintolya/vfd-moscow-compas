# Фото перегородок ALUM

Оригиналы картинок для страницы **«Перегородки ALUM»** — `/partitions/alum/`.
На сайте название фабрики-производителя не упоминается (решение владельца).
Источник фото и фактов — сайт фабрики (название и адрес — у владельца сайта,
в репозиторий не записываются), октябрь 2026. Фото раскладок и комплектующих с логотипом фабрики на сайт не
берём (стирать логотип с чужих фото нельзя): раскладки на странице нарисованы
по их геометрии (`src/components/partitions/AlumLeaf.astro`), комплектующие —
списком. Фото без логотипа сюда можно положить, если фабрика их даст.

На сайт эти файлы напрямую не попадают: скрипт делает из них облегчённые `.webp`
в `public/renders/alum-partitions/`.

## Что где лежит

| Файл | Где на странице |
|---|---|
| `info/interior.jpg` | первый экран — перегородки в интерьере |
| `info/layouts.jpg` | схема всех десяти раскладок |
| `info/profile-colors.jpg` | цвета профиля |
| `info/opti-white.jpg` | сравнение стекла Opti White и обычного |

## Как заменить или добавить фото

1. Положите новый файл **с тем же именем** в эту папку (jpg, png или webp).
2. Выполните в корне проекта:

   ```bash
   npm run gen:alum
   ```

3. Если изменились пропорции картинки — обновите `width` / `height` в
   `src/data/alum-partitions.ts` (скрипт печатает новые размеры).

Новая раскладка — строка в `MODELS` в `src/data/alum-partitions.ts` (номер,
название, геометрия перекладин, отделка для рисунка). Рисунок, подпись
«… 12 секций», схема в конструкторе и счётчик раскладок в текстах соберутся сами.

Все тексты страницы — заголовки, вводки, характеристики, шаги заказа,
вопросы — тоже в `src/data/alum-partitions.ts`. Цифры фабрики (высота и
ширина створки, срок, толщина стекла) заданы один раз, в `ALUM_SPEC`:
поменяйте там — изменится везде. Вёрстка — `src/pages/partitions/alum.astro`.
