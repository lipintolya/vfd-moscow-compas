# Рендеры страницы «Стеновые панели»

Сюда кладутся рендеры для `/catalog/stenovye-paneli/` и плитки «Стеновые панели» на главной.

- Имя файла — место на странице: `<место>.jpg` (или `.png`, `.webp`). Список мест, их пропорции и подписи — `src/data/wall-panels-page.ts` (поле `slot`).
- Пропорция — как у места: `4:5` (вертикальный кадр, от 1200 px по ширине) или `16:10` у плитки на главной (от 1600 px).
- После добавления, замены или удаления файла: `npm run gen:wall-panels`, затем проверить страницу.

Рендер места показывается вместо фото с объекта. Где нет ни рендера, ни фото, в режиме разработки (`npm run dev`) на странице видна рамка «Место для рендера» с именем файла, а сборка перечисляет такие места в предупреждении `[wall-panels]`.
