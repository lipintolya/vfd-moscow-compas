# Рендеры путеводителя входных дверей

Сюда кладём рендеры для блоков под каталогом на `/catalog/vhodnye-dveri/`.
Имя файла — название места (`guide-house.jpg`, `lobby-1.webp`, …),
формат jpg, png или webp. Затем: `npm run gen:entrance-renders`.

Список мест, пропорция каждого и описание «что нарисовать» — в
`src/data/entrance-guide.ts`, массив `GUIDE_VISUALS` (в режиме разработки
то же видно прямо на странице: пустое место — пунктирная рамка с описанием).

Пока рендера нет, блок остаётся текстовым. `lobby-1…3` — кадры слайдера «Как дверь смотрится на площадке» (3:2, без подписей).

Правила: на рендерах без логотипов, вывесок, текста и названий производителей.

`house-<модель>.webp` — рендеры «дверь на доме»: модель каталога на фасаде частного дома. Имя файла и привязка к модели
(`door` — id из `src/data/entrance-doors-catalog.json`), описание кадра и обложка страницы — в `src/data/entrance-scenes.ts`
(`DOOR_SCENES`). Обложка (`cover: true`, одна) — фон первого экрана каталога; остальные — лента на каталоге и блок на странице
модели. Несколько кадров одной модели — `house-<модель>-<что>.webp` (например `-tall`). Без логотипов, вывесок, текстов и марок
(в том числе марок автомобилей: шильдик на кадре — это название производителя).
