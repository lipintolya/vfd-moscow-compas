# Рендеры путеводителя входных дверей

Сюда кладём рендеры для блоков под каталогом на `/catalog/vhodnye-dveri/`.
Имя файла — название места (`guide-house.jpg`, `kind-thermo.png`, …),
формат jpg, png или webp. Затем: `npm run gen:entrance-renders`.

Список мест, пропорция каждого и описание «что нарисовать» — в
`src/data/entrance-guide.ts`, массив `GUIDE_VISUALS` (в режиме разработки
то же видно прямо на странице: пустое место — пунктирная рамка с описанием).

Пока рендера нет: у видов дверей (`kind-*`) на месте стоит фото модели из
каталога, у `guide-house` и `guide-anatomy` блок остаётся текстовым.

Правила: на рендерах без логотипов, вывесок, текста и названий производителей.
