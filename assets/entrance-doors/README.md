# Входные двери — исходники фото

Ассортимент, фото и характеристики входных дверей предоставил партнёр салона
(завод-изготовитель; выгрузка и обработка водяных знаков согласованы, название завода — у владельца сайта). **Название завода на сайте не
выводится** — ни в текстах, ни в адресах, ни в alt, ни в разметке; здесь
оно в репозиторий не записывается (репозиторий публичный).

- Файлы `<модель>-<n>.webp` — кадр «дверь снаружи + дверь изнутри». Размер
  бывает двух видов:
  - **1000×977 — дверь в полную высоту.** Логотип партнёра и серые плашки снизу
    убраны нейросетью (LaMa, `tools/remove-watermarks.py`), верх кадра — как
    в оригинале с закрашенной меткой в углу. Так сделаны: Айслаб, Бетон,
    Бункер БН-02/05/06/09/12, Инфинити, Иссида, Карбон, Классик антик медный,
    Лаб 3 смарт, Лофт, Пазл, Пиано, Роял, Сиана, Урбан. Нижняя часть
    достроена, а не снята: на внутренней стороне у отдельных вариантов
    отделки мелкие детали внизу (рёбра, края стекла) могут отличаться
    от настоящих.
  - **~1010×977 — снаружи и изнутри, собрано из двух частей.** Наружная сторона —
    прежний кадр (см. выше), внутренняя — с кадра этой же отделки у партнёра
    (оригинал 1000×977, правая половина от белой полосы). На внутренней стороне
    убран только логотип справа внизу (LaMa, прямоугольник 625–915 × 855–960
    в координатах оригинала), остальное — как в оригинале. Отделка подобрана
    по названию: номер дизайна, тип зеркала и цвет должны совпасть с файлом
    партнёра; неоднозначные — проверены глазами (контрольные листы не в репозитории).
    Сделаны: 203 отделки (`src/data/entrance-doors.ts` берёт всё автоматически).
  - **~500×977 (или 967) — только наружная сторона, в полную высоту.** 59 отделок,
    для которых у партнёра нет кадра с накладкой (зеркала «Панорама/Максимум» с
    тонировкой, «зеркальная вставка», «Зеркало 18/19/32» на страницах, где их нет).
    Такие отделки на сайте не показываются (`build()` в `src/data/entrance-doors.ts`);
    единственный кадр остаётся, только если у модели нет ни одной отделки с накладкой.
  - **Семь моделей (Тундра Плюс, Верса, Норд Плюс, Скандия, Фрост 7024, Имперо,
    Термолаб 2 Про) — наружная сторона прежняя, внутренняя — правая половина
    двусторонней фотографии партнёра той же модели.** Исходный кадр партнёра —
    1000×977 с белой полосой: слева наружная сторона, справа внутренняя; LaMa убирает
    логотип справа внизу и серые плашки, метка в левом верхнем углу закрашена узким
    прямоугольником (швы двери не трогаем). Файл `<модель>-1.webp` — 1000×975,
    слева наружная, справа внутренняя сторона.
  Маленькая метка в левом верхнем углу закрашена по рамке, заданной для
  каждой коллекции. **Верх двери не обрезаем.** Первый файл модели — обложка.
  Страницы берут пропорции кадра из `src/data/entrance-doors-images.json`
  (карточки, шапка, страница модели), так что оба размера сосуществуют.
- Цены не публикуются: на сайте «цена по запросу».
- Данные (названия, характеристики, подписи вариантов) — `src/data/entrance-doors-catalog.json`.
- Дальше: `npm run gen:entrance-doors` → `public/renders/entrance-doors/`.
