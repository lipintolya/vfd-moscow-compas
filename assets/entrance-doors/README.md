# Входные двери — исходники фото

Ассортимент, фото и характеристики входных дверей предоставил партнёр салона
(завод-изготовитель; выгрузка и обработка водяных знаков согласованы, название завода — у владельца сайта). **Название завода на сайте не
выводится** — ни в текстах, ни в адресах, ни в alt, ни в разметке; здесь
оно в репозиторий не записывается (репозиторий публичный).

- Файлы `<модель>-<n>.webp` — кадр «дверь снаружи + дверь изнутри». Размер
  бывает двух видов:
  - **1000×977 — дверь в полную высоту.** Логотип партнёра и серые плашки снизу
    убраны нейросетью (LaMa, `tools/remove-watermarks.py`), верх кадра — как
    в оригинале с закрашенной меткой в углу. Так сделаны: Айслаб, Бетон,
    Бункер БН-02/05/06/09/12, Инфинити, Иссида, Карбон, Классик антик медный,
    Лаб 3 смарт, Лофт, Пазл, Пиано, Роял, Сиана, Урбан. Нижняя часть
    достроена, а не снята: на внутренней стороне у отдельных вариантов
    отделки мелкие детали внизу (рёбра, края стекла) могут отличаться
    от настоящих.
  - **~500×977 (или 967) — только наружная сторона, в полную высоту.** У
    остальных коллекций нейросеть на внутренней стороне дорисовывала лишнее
    (рёбристые панели с овальным стеклом — она рисовала стекло шире настоящего),
    поэтому внутреннюю дверь из кадра убрали: остаётся наружная, очищенная
    от логотипа и плашек так же. Ширина — до белой полосы между дверями
    (одна на модель). Страница модели в этом случае подписывает «Снаружи» и
    ставит фото по центру колонки.
  Маленькая метка в левом верхнем углу закрашена по рамке, заданной для
  каждой коллекции. **Верх двери не обрезаем.** Первый файл модели — обложка.
  Страницы берут пропорции кадра из `src/data/entrance-doors-images.json`
  (карточки, шапка, страница модели), так что оба размера сосуществуют.
- Цены не публикуются: на сайте «цена по запросу».
- Данные (названия, характеристики, подписи вариантов) — `src/data/entrance-doors-catalog.json`.
- Дальше: `npm run gen:entrance-doors` → `public/renders/entrance-doors/`.
